# Image Model Fetcher Skill

## Description
ใช้สำหรับดึง จัดการ หรือสร้างภาพโมเดลและสื่อมีเดีย (เช่น ฟิกเกอร์, โมเดล 3D, ภาพตัวอย่างสินค้า, Mockup, แบนเนอร์) เพื่อนำมาใช้งานในโปรเจกต์ร้าน FriendHouse

## Instructions
1. **ประเมินบริบท**: เมื่อผู้ใช้ขอ "รูปโมเดล", "ภาพสินค้า", "3D โมเดล" หรือต้องการสื่อประกอบ ให้ประเมินบริบทของร้าน FriendHouse (ร้านขายโมเดลและฟิกเกอร์แท้)
2. **การตั้งชื่อและฟอร์แมต**:
   - ตรวจสอบฟอร์แมตไฟล์ให้ถูกต้อง (`.png`, `.jpg`, `.webp`, `.glb`, `.mp4`)
   - ตั้งชื่อไฟล์ให้ตรงกับสิ่งที่แสดงอย่างชัดเจน (เช่น `naruto_kyubi_sage.glb`, `naruto_figure_preview.png`, `hero_banner.jpg`) ห้ามตั้งชื่อมั่วหรือใช้ชื่อสุ่ม
3. **จัดเก็บในแหล่งรวม Media**:
   - บันทึกไฟล์มีเดียทั้งหมดลงในโฟลเดอร์ส่วนกลางของโปรเจกต์:
     - รูปภาพ: `wwwroot/media/images/`
     - โมเดล 3D: `wwwroot/media/models/`
     - วิดีโอ: `wwwroot/media/videos/`
4. **การแสดงผลและเรียกใช้งาน**:
   - ประกาศ Path และ Object ของ Media ไว้ที่ส่วนบนสุดของไฟล์ View (`.cshtml`) เสมอ
   - แสดงตัวอย่างรูปภาพหรือลิงก์ในแชทให้ผู้ใช้เห็นผ่าน Markdown: `![Model Image](file:///d:/code/CSI402/Khetsophon_CSI402_8456/wwwroot/media/images/filename.png)`
